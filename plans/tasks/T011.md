# T011 回零接口

- 所属模块：Device SDK
- 初始状态：BLOCKED
- 前置依赖：T007

## 功能目标

在证据确认现场关节支持回零之后，再增加回零调用。eRob 表 5-1 写明回零暂不支持时，本任务不提供 API。

## 输入依据

- `specs/protocol_spec.md` 第 4.3 节：固高回零要满足使能、回零模式和回零参数，否则返回 1 且不动作
- 同文第 8.3 节：eRob `0x06` 暂不支持
- `specs/unresolved.md` 的 C7
- `specs/sdk_api.md`：公开 API 不提供回零

## 接口契约

阻塞期间不增加 `home()` 或 `GTN_StartEcatHoming` 的包装。解除阻塞后的参数单位以新证据为准，不沿用例程 5-2 里“以 GTHD 为例”的速度数字作为本机参数。

## 实施范围

T007 确认支持回零之前，不改源码。

## 允许修改的文件

阻塞期间无。解除后仅限届时任务复核所点名的设备 SDK 与对应测试，且不得修改 `gtn_native_api.*`。

## 禁止修改的范围

- 固高原生 API 头文件和实现
- 标定、ENI、消息定义
- 把模式 6 写进周期循环

## 测试方案

解除阻塞前没有测试可跑。解除后用注入 API 覆盖“三条件缺一时返回失败且不调用启动函数”。不在实机回零。

## 验收标准

阻塞期间相关源码无 diff。解除后的测试退出码为 0，且接口注释引用 T007 的来源，而不是例程 5-2 的示例速度。

## 风险及回滚

把 GTHD 示例参数或 eRob“暂不支持”的 0x06 做成默认回零，即任务失败。回滚时删除新增接口和测试。

## 阻塞原因

依赖 T007。2026-10-28 拍板驱动器回零按 eRob V1.11，模式 `0x06` 不支持，不实现 `GTN_StartEcatHoming`。现有 PVT 回机械零位保持原样。不能用固高例程 5-2 的示例参数开工。
