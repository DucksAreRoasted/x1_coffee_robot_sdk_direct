# 资料来源与阅读范围

路径以仓库内实际目录 `manual/` 为准。不存在 `manuals/`。

阅读方式：PDF 使用 `pdftotext -layout` 按分页符切页，下文“PDF页”是该文件的物理页序（从 1 起）。能看到页脚印页时同时记录。DOCX 从 `word/document.xml` 提取段落，没有可靠分页，只引用章节和文档自带目录页码。PPT 经 LibreOffice 转为 PDF 后再提取文字；幻灯片上的“Page N”与转换后的 PDF 页基本对齐。图、照片和未转成文字的表格不算已阅读。

核实等级：

- VERIFIED：该文件中有明确句子、表格或例程。
- INFERRED：只能从多份资料拼出，尚未被同一处原文确认。
- CONFLICT：两处原文不一致。
- UNKNOWN：资料没有给出。

只有 VERIFIED 可以作为协议实现依据。
