# MIT 关节控制设计（CST 软件实现）

## 已确认路径

本仓库使用 SOEM 主站，周期线程在 `soem_ethercat_transport.cpp::cycleLoop()` 中收发过程数据，并使用 DC 节拍。eRob EtherCAT 手册 V1.11 第 5.9 节确认 `0x6060=0x0A` 为 CST：主站周期发送 `0x6040` 和 `0x6071`。现有 PDO 映射如下：

- RxPDO `0x1600`：`0x6040`、`0x607A`、`0x6071`、`0x6060`、8 位填充。
- TxPDO `0x1A00`：`0x6041`、`0x6064`、`0x606C`、`0x6077`、`0x6078`、`0x6061`、8 位填充。
- `0x6071/0x6077/0x6078` 单位为额定电流千分比；`0x6075` 是 mA；`0x6076` 是 mN·m。

手册没有给出“MIT”原生对象或参数帧，因此本项目采用上位机计算：

```
tau = kp * (q_des - q) + kd * (dq_des - dq) + tau_ff
```

再使用逐轴已验证的 `nm_per_permille` 转换到 `0x6071`。驱动器未提供或尚未验证该转换时，配置会拒绝启动，不能从型号、齿轮比或猜测的 Kt 自动推断。

## 新模块

`mit_controller.hpp/.cpp` 提供与 EtherCAT 传输解耦的 14 轴控制会话：

- SI 单位的 `MITCommand`、`MITJointState` 和逐轴 `MITLimits`。
- PD 加前馈、参数渐变、力矩限幅、力矩变化率限制。
- 位置、速度、实际力矩、周期时间、总线/使能/腰部 CSP、模式和命令租约检查。
- 进入时从反馈力矩接续，故障锁存；故障后不能通过参数更新自动恢复。
- 无锁单生产者/单消费者邮箱，控制周期内不做文件、SDO、日志或动态分配。
- `initialGains()` 只按 `Jω²` 和 `2ζJω-B` 给出初值，必须经仿真和单关节实机验证。

现有 `SoemEthercatTransport` 的右臂手感入口仍保留作为兼容路径；新模块是后续把双臂 14 轴控制从键盘服务接入实时线程的安全边界。当前没有把未经验证的参数接入实机默认启动。
